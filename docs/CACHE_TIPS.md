# 🔧 网页缓存问题解决指南

## ❓ 问题现象

修改了源代码（HTML/CSS/JavaScript），但网页刷新后看不到变化。

## 🔍 为什么会这样？

浏览器为了加快加载速度，会缓存静态文件（HTML、CSS、JS）。即使服务器上的文件已更新，浏览器仍会使用缓存中的旧版本。

### 缓存链路

```
你的代码 → 文件系统 → Express 服务器 → 网络传输 → 浏览器缓存
                                           ↑
                                    问题通常在这里
```

---

## ✅ 解决方案

### 【快速方案】硬刷新（临时）

**Windows/Linux:**

```
Ctrl + Shift + R
```

**Mac:**

```
Cmd + Shift + R
```

> ⚡ 清除当前页面的缓存并重新加载（最快）

---

### 【开发方案】禁用缓存

#### 1️⃣ 使用浏览器开发者工具

**步骤：**

1. 按 `F12` 打开开发者工具
2. 点击 `⚙️ Settings`（右上角）
3. 找到 `Network` 标签
4. 勾选 `Disable cache (when DevTools is open)`
5. 保持开发者工具打开

**效果：** 开发者工具打开时，浏览器自动禁用缓存

**优点：**

- ✓ 简单快速
- ✓ 只影响当前标签页

**缺点：**

- ✗ 需要开发者工具一直打开
- ✗ 稍微影响性能

---

#### 2️⃣ 完全清除浏览器缓存

**步骤：**

1. 按 `Ctrl + Shift + Delete` 打开缓存清除对话框
2. 选择时间范围：**所有时间**
3. 勾选：
   - ☑️ Cookie 和其他网站数据
   - ☑️ 缓存的图片和文件
4. 点击 **删除数据**

**效果：** 彻底清除浏览器缓存

**优点：**

- ✓ 彻底解决问题
- ✓ 无性能影响

**缺点：**

- ✗ 需要每次手动清除
- ✗ 会清除其他网站的缓存

---

### 【永久方案】配置服务器（已完成）✅

我已经为你修改了 `server.js`，添加了**禁用缓存头**：

```javascript
// 禁用静态文件缓存 - 确保修改立即生效
app.use((req, res, next) => {
  res.set("Cache-Control", "no-store, no-cache, must-revalidate, proxy-revalidate");
  res.set("Pragma", "no-cache");
  res.set("Expires", "0");
  next();
});
```

**做了什么：**

- `Cache-Control`: 告诉浏览器不要缓存任何东西
- `Pragma`: 向后兼容 HTTP/1.0 缓存指令
- `Expires`: 设置过期时间为过去

**效果：**

- ✅ 修改代码后，F5 刷新就能看到变化
- ✅ 无需硬刷新（Ctrl+Shift+R）
- ✅ 无需手动清除缓存
- ✅ 对性能基本无影响

**优点：**

- ✓ 完全自动化
- ✓ 开发体验最好
- ✓ 无需额外操作

### 开发阶段（当前）

```
1. 修改源代码（HTML/CSS/JS）
2. 保存文件
3. 按 F5 刷新（自动获取最新版本）
4. 看到变化 ✓
```

> 由于已配置缓存头，修改后直接 F5 即可看到效果

### 生产环境（上线时）

如果要改为缓存模式（提升性能），可以：

```javascript
// 缓存静态资源 30 天
app.use(
  express.static("public", {
    maxAge: "30d", // 30 天
  }),
);
```

但目前开发阶段推荐保持禁用缓存。

## 🔧 故障排除

### 还是看不到变化？

#### 检查 1️⃣：是否真的改了文件？

```bash
# Windows PowerShell
cat .\public\reader.html | Select-String "你改的内容"

# 或直接在编辑器中查看文件
```

#### 检查 2️⃣：服务器是否重启？

如果使用 Docker：

```bash
# 重启容器
docker-compose restart

# 或重新构建
docker-compose up -d --build
```

#### 检查 3️⃣：浏览器开发者工具

打开 F12，在 Network 标签中查看响应头：

```
Cache-Control: no-store, no-cache, must-revalidate, proxy-revalidate
Pragma: no-cache
Expires: 0
```

如果看到这些头，说明配置成功！

#### 检查 4️⃣：尝试无痕模式

```
Ctrl + Shift + N（无痕窗口）
```

无痕模式不使用浏览器缓存，如果能看到变化，说明问题确实是缓存。
