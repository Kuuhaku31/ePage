# 📖 漫画阅读器 - 更新说明

## 🎯 新增功能

已将应用扩展为完整的**漫画阅读程序**，支持双页显示和流畅翻页。

### ✨ 核心功能

#### 1. 浏览列表视图

- 加载漫画文件夹后，显示所有页面的缩略图网格
- 每个缩略图显示：页码、文件大小
- **点击任意页面进入阅读模式**，并从该页开始阅读

#### 2. 漫画阅读模式

- **两页并排显示**：左页 + 右页
- **页码自动递增**：每次翻页增加或减少 2 页
- **实时页码显示**：顶部显示 "第 X-X 页 / 共 XX 页"

#### 3. 翻页方式（五种方法）

| 方式         | 操作             | 说明         |
| ------------ | ---------------- | ------------ |
| 左右箭头按钮 | 点击界面左右按钮 | 推荐 PC 使用 |
| 键盘左右键   | ← / →            | 标准方向键   |
| 快捷键 A/D   | 按 A 或 D 键     | 游戏风格     |
| 触摸滑动     | 向左/右滑动屏幕  | 移动设备友好 |
| 进度条拖动   | 拖动底部滑块     | 快速定位     |

#### 4. 其他快捷键

| 快捷键 | 功能     |
| ------ | -------- |
| `F`    | 全屏阅读 |
| `Esc`  | 返回列表 |

#### 5. 全屏模式

- 按 `F` 进入全屏，隐藏导航栏和控制栏
- 再次按 `F` 或 `Esc` 退出
- 支持浏览器全屏 API

## ⌨️ 键盘快捷键完全指南

### 翻页快捷键

```
← 键或 A 键   = 上一页（页码 -2）
→ 键或 D 键   = 下一页（页码 +2）
```

### 功能快捷键

```
F        = 切换全屏
Esc      = 返回列表
```

### 示例场景

**场景 1：快速翻页**

```
1. 按 → 翻到第 3-4 页
2. 按 → 翻到第 5-6 页
3. 按 ← 回到第 3-4 页
```

**场景 2：全屏阅读**

```
1. 按 F 进入全屏（界面消失）
2. 用方向键 / WASD 翻页
3. 按 F 或 Esc 退出全屏
```

**场景 3：触摸阅读（手机/平板）**

```
1. 从屏幕右边向左滑动 → 下一页
2. 从屏幕左边向右滑动 ← 上一页
3. 长按返回按钮 → 返回列表
```

## 🔍 页码计算逻辑

### 重要概念

- **内部索引**：从 0 开始（第 1 页 = 索引 0）
- **显示页码**：从 1 开始（对用户友好）
- **双页模式**：每次翻页 +2/-2

### 计算示例

| 点击页码 | 左页显示  | 右页显示 | 索引值 |
| -------- | --------- | -------- | ------ |
| 第 1 页  | 第 1 页   | 第 2 页  | 0      |
| 第 3 页  | 第 3 页   | 第 4 页  | 2      |
| 第 5 页  | 第 5 页   | 第 6 页  | 4      |
| 最后一页 | 第 N-1 页 | 第 N 页  | N-2    |

### 翻页时的页码变化

```
起始：第 1-2 页（索引 0）
  ↓ 点击下一页
第 3-4 页（索引 2）
  ↓ 点击下一页
第 5-6 页（索引 4）
  ↓ 点击上一页
第 3-4 页（索引 2）
```

## 🔄 数据流程

### 加载漫画

```
用户输入路径 "img/a"
    ↓
POST /api/images 请求后端
    ↓
后端返回该文件夹所有图片元数据
    ↓
存储在 sessionStorage（避免重复请求）
    ↓
显示缩略图网格
```

### 进入阅读模式

```
用户点击第 X 页缩略图
    ↓
保存数据到 sessionStorage：
  - mangaPath: "img/a"
  - mangaImages: [所有图片数据]
  - startIndex: X（从第几页开始）
    ↓
导航到 reader.html
    ↓
reader.html 从 sessionStorage 读取数据
    ↓
显示第 X-X+1 页
```

### 返回列表

```
用户按 Esc 或点击返回
    ↓
保存当前位置
    ↓
导航回 index.html
    ↓
index.html 从 sessionStorage 恢复列表
    ↓
显示相同的漫画（无需重新加载）
```

## ⚡ 性能优化

### 图片预加载

- 当前显示的两页：立即加载
- 相邻的两页：后台预加载（提升翻页速度）

### 懒加载

- 缩略图：使用 `loading="lazy"` 逐步加载
- 阅读器：只加载当前和相邻页面

### 缓存策略

- 图片列表缓存在 sessionStorage
- 用户返回时无需重新请求后端
- 页面导航不刷新，保持上下文

## 🆘 常见问题

### Q: 进入阅读模式后如何返回列表？

A: 按 `Esc` 键或点击头部的"← 返回"按钮。

### Q: 如何从中间某页开始阅读？

A: 在列表视图中点击该页的缩略图。

### Q: 为什么只能两页两页翻？

A: 这是漫画阅读的标准方式。两页对页（跨页）是漫画设计的核心。

### Q: 支持单页模式吗？

A: 当前版本固定为双页模式。单页模式可在未来版本添加。

### Q: 最后一页如何显示？

A: 如果总页数为奇数，最后一次翻页时右页为空。

### Q: 触摸滑动失效？

A: 确保滑动距离足够（至少 50px）。轻微滑动不会触发翻页。

### Q: 在手机上看不到按钮？

A: 手机版本的按钮会自动调整位置。使用触摸滑动或键盘。
