# 📖 漫画阅读器 - 阅读方向功能更新

## 🎯 新增功能

### 1. 阅读方向切换 ⭐

**两种阅读模式**：

- **从左到右（LTR）**：适合欧美、中文漫画
- **从右到左（RTL）**：适合日本漫画（**默认模式**）

### 2. 模式特性

#### 从左到右（LTR）

```
┌──────────────────────┐
│ 左页(页码小) │ 右页  │
│     1-2    │ 3-4   │
└──────────────────────┘
   ↑ ←     →
   翻页逻辑：← 上一页、→ 下一页
```

#### 从右到左（RTL）【默认】

```
┌──────────────────────┐
│ 左页(页码大) │ 右页  │
│     3-4    │ 1-2   │
└──────────────────────┘
   ↑ ←     →
   翻页逻辑：← 下一页、→ 上一页
```

### 3. 阅读方向切换方式

**三种切换方法**：

1. **按钮切换**：点击头部的"📖/📚"按钮
2. **快捷键**：按 `R` 键切换
3. **记忆保存**：切换后自动保存，返回时保持设置

### 4. 进度条自适应

**根据阅读方向调整进度**：

| 模式 | 进度条逻辑 | 示例                 |
| ---- | ---------- | -------------------- |
| LTR  | 从前往后   | 1→2→3→4（正向）      |
| RTL  | 从后往前   | 100→99→98→97（反向） |

## 🔄 工作原理

### 从左到右（LTR）模式

```
页面顺序：
  左页显示第 1 页、右页显示第 2 页
  → 点击下一页按钮
  → 左页显示第 3 页、右页显示第 4 页

翻页按钮：
  ← 上一页（回到 1-2 页）
  → 下一页（前进到 3-4 页）

进度条：
  显示 1-2 表示第 1-2 页
  拖动到 50% 显示中间页面
```

### 从右到左（RTL）模式【默认】

```
页面顺序：
  右页显示第 1 页、左页显示第 2 页（视觉上页码从右到左递增）
  → 点击下一页按钮（→）
  → 右页显示第 3 页、左页显示第 4 页（向后翻）

翻页按钮：
  ← 下一页（继续阅读）
  → 上一页（返回）

进度条：
  显示 100-99 表示最后两页
  从 100 往 1 递减（反向显示）
```

## ⌨️ 快捷键对照表

### RTL 模式（默认）

```
← 键 或 A 键 = 下一页（继续阅读）
→ 键 或 D 键 = 上一页（返回）
R 键        = 切换为 LTR
F 键        = 全屏
Esc 键      = 返回列表
```

### LTR 模式

```
← 键 或 A 键 = 上一页（返回）
→ 键 或 D 键 = 下一页（继续阅读）
R 键        = 切换为 RTL
F 键        = 全屏
Esc 键      = 返回列表
```

## 📊 页码显示逻辑

### LTR 模式

```
当前页码索引 = 0 时显示 1-2
当前页码索引 = 2 时显示 3-4
当前页码索引 = 4 时显示 5-6

页码 = 索引 + 1
```

### RTL 模式

```
当前页码索引 = 0 时显示 3-4（从 100 倒数）
当前页码索引 = 2 时显示 1-2
当前页码索引 = 4 时显示 99-100（从后往前）

页码 = 总页数 - 索引
```

## 🔧 技术实现

### 状态管理

```javascript
isRTL = true; // 全局标志
READING_MODE.RTL; // 'rtl'
READING_MODE.LTR; // 'ltr'
```

### 存储保存

```javascript
sessionStorage.setItem("readingMode", isRTL ? "rtl" : "ltr");
// 用户返回列表后重新进入时恢复该模式
```

### 页面排列

```javascript
if (isRTL) {
  pagesContainer.classList.add("rtl");
  // CSS flex-direction: row-reverse
}
```

### 翻页逻辑

```javascript
function prevPage() {
  if (isRTL) {
    nextPage(); // RTL 下 ← 实际是下一页
  } else {
    // LTR 下 ← 是上一页
  }
}
```

## ❓ 常见问题

### Q：为什么默认是 RTL（从右向左）？

A：因为大多数用户使用日本漫画，日本漫画的标准阅读方向就是从右向左。

### Q：如何在 LTR 和 RTL 之间快速切换？

A：按 `R` 键一次即可切换，无需鼠标。

### Q：阅读模式会保存吗？

A：会的。返回列表后再进入同一部漫画时，会恢复之前的模式。

### Q：不同漫画可以有不同的阅读模式吗？

A：可以。系统为每次阅读会话保存模式，但不同漫画切换时模式会跟随。

### Q：为什么切换模式后按 ← 键的功能改变了？

A：这是设计特意的。在 RTL 模式下，← 键表示继续阅读（从右向左）；在 LTR 模式下，← 键表示返回（从左向右）。

### Q：进度条在 RTL 模式下是反向的吗？

A：是的。RTL 模式下进度条从右往左计算（100→1），正确反映阅读进度。
