## ⭐ 核心功能实现

### 1. 双页阅读模式 ✅

```
当用户点击任意图片时：
  ✓ 进入 reader.html
  ✓ 显示该页 + 下一页（两页并排）
  ✓ 左页标注"左页码"，右页标注"右页码"
  ✓ 头部显示"第 X-Y 页 / 共 Z 页"
```

### 2. 智能翻页系统 ✅

```
页码递增规则：
  第 1-2 页 ← → 第 3-4 页 ← → 第 5-6 页

每次翻页：
  • 点击下一页：页码 +2
  • 点击上一页：页码 -2
  • 自动限制边界（不会翻过头）
```

### 3. 五种翻页方式 ✅

| #   | 方式       | 控制方式     | 适用场景  |
| --- | ---------- | ------------ | --------- |
| 1   | 鼠标按钮   | 点击左右箭头 | PC 用户   |
| 2   | 键盘方向键 | ← / →        | 标准键盘  |
| 3   | 快速键盘   | A / D        | 游戏风格  |
| 4   | 触摸滑动   | 向左/右滑    | 手机/平板 |
| 5   | 进度条     | 拖动滑块     | 快速定位  |

### 4. 快捷键支持 ✅

| 按键  | 功能 | 说明       |
| ----- | ---- | ---------- |
| ← / → | 翻页 | 标准方向键 |
| A / D | 翻页 | 快速键盘   |
| F     | 全屏 | 沉浸式阅读 |
| Esc   | 返回 | 回到列表   |

### 5. 全屏模式 ✅

```
按 F 键：
  • 隐藏所有 UI 元素
  • 最大化显示漫画内容
  • 仍支持快捷键操作
  • 按 F 或 Esc 退出
```

### 6. 响应式设计 ✅

```
设备适配：
  • 桌面版：两页横排，充分展开
  • 平板版：两页适中显示
  • 手机版：两页竖排或单页
  • 所有设备支持触摸翻页
```

## 🚀 使用方法

### 快速启动

```bash
# Windows：双击
start.bat

# 或命令行
cd d:\html\RPage
docker-compose up --build
```

### 打开浏览器

```
http://localhost:3000
```

### 三步使用

1. 输入漫画路径（如 `img/a`）
2. 点击"加载漫画"
3. 点击任意缩略图进入阅读
4. 使用 ← / → 或 A / D 翻页
