## 🎯 新增核心功能

### 1. 双页阅读模式 (Two-Page Spread)

- 点击任意缩略图 → 进入阅读模式
- 左右两页并排显示（符合漫画阅读习惯）
- 自动识别页码并正确显示

### 2. 智能翻页系统

每次翻页 **页码 ± 2**（跨页翻法）

```
第 1-2 页 → 第 3-4 页 → 第 5-6 页 ...
```

### 3. 五种翻页方式

1. **鼠标**：点击左右箭头按钮
2. **键盘方向键**：← / →
3. **快速键**：A / D
4. **触摸滑动**：向左/右滑动（手机/平板）
5. **进度条**：拖动底部滑块快速定位

### 4. 快捷键支持

| 键位  | 功能                 |
| ----- | -------------------- |
| ← / → | 上下一页             |
| A / D | 上下一页（快速键盘） |
| F     | 全屏阅读             |
| Esc   | 返回列表             |

### 5. 全屏沉浸式阅读

- 按 F 进入全屏，隐藏所有 UI
- 仅保留阅读内容
- 支持浏览器全屏 API

## 💡 使用技巧

### 📖 阅读流程

```
列表视图（所有页面）
    ↓ 点击第 5 页
阅读模式（显示第 5-6 页）
    ↓ 按右键
阅读模式（显示第 7-8 页）
    ↓ 按 Esc
回到列表视图
```

### ⚡ 快速导航

- 使用**滑块**快速跳转到任意页面
- 例如：想看第 50 页，拖动滑块到中间位置

### 🎮 游戏式操作

```
使用 WASD 键盘布局：
  A = 上一页
  D = 下一页
（这样手指无需移动，从游戏切换很流畅）
```

### 📱 手机友好

```
触摸阅读：
  从右 → 左 滑动 = 下一页
  从左 ← 右 滑动 = 上一页

长按返回按钮 = 立即返回列表
```

## 🔄 数据流程

### 工作流：

```
┌─ 列表视图
│  ├─ 输入路径 "img/a"
│  ├─ 加载漫画（后端 API）
│  ├─ 显示所有页面缩略图
│  └─ 用户点击第 5 页
│
├─ 进入阅读模式
│  ├─ 保存状态到 sessionStorage
│  ├─ 导航到 reader.html
│  └─ 显示第 5-6 页
│
├─ 阅读和翻页
│  ├─ 用户翻页
│  ├─ 页面数据从 sessionStorage 读取
│  ├─ 更新显示（无需新请求）
│  └─ 支持前后翻页
│
└─ 返回列表
   ├─ 用户按 Esc
   ├─ 保存当前位置
   ├─ 导航回 index.html
   └─ 列表自动恢复
```

## 📊 页码计算

### 重要概念

- **双页跨页**：每页显示 2 张图片
- **页码递增**：每次翻页 +2
- **最后一页**：可能只显示 1 张（奇数总数）

### 示例

| 操作         | 显示页码 | 显示图片     |
| ------------ | -------- | ------------ |
| 初始加载     | 1-2      | 第 1、2 页   |
| 按下一页     | 3-4      | 第 3、4 页   |
| 再按下一页   | 5-6      | 第 5、6 页   |
| 按上一页     | 3-4      | 第 3、4 页   |
| 最后一次翻页 | 11-12    | 第 11、12 页 |

## 💬 快速问答

**Q：为什么点击列表中的第 5 页，阅读时却显示 5-6 页？**
A：这是设计目标。每次显示 2 页（跨页），从你选择的页面开始。

**Q：最后一页是单页还是双页？**
A：如果总页数为奇数，最后一次翻页时右页为空（只显示左页）。

**Q：支持自定义快捷键吗？**
A：当前不支持，但可以手动修改 reader.html 中的 JavaScript 代码。

**Q：离线也能用吗？**
A：需要 Docker 和图片文件，在本地完全工作（不需要网络）。
