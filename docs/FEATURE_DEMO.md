### 2️⃣ 双页显示逻辑

#### 页码计算规则

```
用户点击的页码 → 显示该页和下一页

例1：点击第 1 页
  显示 → 左页(1) + 右页(2)

例2：点击第 5 页
  显示 → 左页(5) + 右页(6)

例3：点击第 20 页（最后一页）
  显示 → 左页(19) + 右页(20)

例4：20 页漫画，点击第 19 页
  显示 → 左页(19) + 右页(20)
```

#### 翻页时的页码变化

```
初始状态：1-2 页
  ↓ 点击右箭头
3-4 页
  ↓ 点击右箭头
5-6 页
  ↓ 点击左箭头
3-4 页
```

### 3️⃣ 五种翻页方式详解

#### ① 鼠标点击（最直观）

```
阅读器界面：
         ◄ 按这里上一页
┌──────────────────────┐
│   左页  │   右页     │
│ (1-2)  │  (1-2)    │
└──────────────────────┘
         ► 按这里下一页
```

#### ② 键盘方向键（标准方式）

```
按 ← 键  → 上一页
按 → 键  → 下一页

最常用的翻页方式
```

#### ③ 快速键盘（游戏风格）

```
按 A 键  → 上一页
按 D 键  → 下一页

手指不需要移动位置
从游戏切换到阅读很流畅
```

#### ④ 触摸滑动（手机友好）

```
手指从屏幕右边向左滑  → 下一页
手指从屏幕左边向右滑  → 上一页

需要滑动距离 > 50px 才能触发
防止误触
```

#### ⑤ 进度条（快速定位）

```
拖动底部滑块快速跳转到任意位置：

[▬▬●▬▬▬▬▬▬▬]  当前位置中间
 ↑
 拖动我可以快速跳页
```

### 5️⃣ 全屏模式详解

#### 普通模式 vs 全屏模式

**普通模式**

```
┌───────────────────┐
│ 导航栏            │ ← 显示标题、页码、按钮
├───────────────────┤
│   阅读内容        │
│  (左页 | 右页)   │
├───────────────────┤
│ 控制栏            │ ← 显示进度条、按钮
└───────────────────┘
```

**全屏模式（按 F 键）**

```
┌───────────────────┐
│   阅读内容        │
│  (左页 | 右页)   │ ← 最大化，不显示 UI
│   阅读内容        │
└───────────────────┘
```

#### 全屏模式下的使用

```
进入全屏后：
  • 所有 UI 元素隐藏
  • 只显示漫画内容
  • 仍可用快捷键翻页（无需 UI）
  • 用方向键或 WASD 翻页
  • 按 Esc 或 F 退出全屏
```

### 7️⃣ 性能特性

#### 数据持久化（sessionStorage）

```
用户工作流程：

加载漫画 → 所有数据存储到 sessionStorage
    ↓
进入阅读 → 从 sessionStorage 读取（无需重新请求）
    ↓
翻页 → 本地更新显示（无需 API 调用）
    ↓
返回列表 → 之前的列表完整保留
    ↓
重新进入 → 直接显示上次的数据
```

#### 图片预加载

```
阅读第 1-2 页时：
  • 立即加载：第 1、2 页
  • 后台预加载：第 3、4 页

翻到第 3-4 页时：
  • 显示：第 3、4 页（已预加载）
  • 预加载：第 5、6 页

优势：翻页流畅，无等待
```

## 🎮 游戏风格操作总结

### WASD 键盘布局

```
为什么用 WASD？
  • 游戏玩家最熟悉的布局
  • 手指位置不需要移动
  • 从游戏切换到阅读无需适应

标准方向键布局
  └─ 对标准用户最直观
  └─ 不用改变手指位置
```

### 使用习惯迁移

```
游戏玩家：
  游戏中用 WASD 移动
  → 阅读时用 AD 翻页
  → 手指位置完全一样

标准用户：
  日常用方向键
  → 阅读时用 ←/→ 翻页
  → 习惯无缝迁移
```
